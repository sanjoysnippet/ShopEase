# ShopEase Advanced Online Shopping App

## Included features
- Product search
- Category filtering
- Sorting by price/rating
- Wishlist
- Add to cart
- Quantity +/-
- Remove items
- LocalStorage cart persistence
- Checkout form
- Customer name, phone, address, city and PIN
- Payment method selection (COD / UPI Demo / Card Demo)
- Place Order flow
- Order ID generation
- My Orders page/panel
- Order history stored in LocalStorage
- Responsive mobile/tablet/desktop UI
- Toast notifications
- Demo order-success screen

## Run in VS Code
1. Extract this ZIP.
2. Open the `online-shopping-app` folder in VS Code.
3. Open `index.html`.
4. Use Live Server if installed, or open the HTML file in a browser.
5. Internet is needed for product images and Google Fonts.

## Important
This is a frontend/demo shopping app. The payment options do NOT charge real money.
For a production e-commerce website, connect:
- Node.js + Express backend
- MongoDB
- Authentication
- Product/order APIs
- Secure payment gateway
- Admin dashboard
- Server-side validation
- Deployment/hosting
